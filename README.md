# 2. HERO SECTION

Create a visually powerful hero section.
The hero should immediately communicate:
- What the company/product is
- What makes it different
- Why the user should care
- The primary action

Use a strong visual composition inspired by the reference image.
Consider:
- Large editorial-style headline
- Short supporting description
- Primary CTA
- Secondary CTA if useful
- Large background/side image or visual composition
- Subtle motion
- Strong whitespace
- Layered elements where appropriate

The hero should feel premium rather than overloaded.
Use a strong visual hierarchy: Headline → supporting copy → CTA → visual proof.

---

# 3. NAVIGATION

Create a clean modern navigation bar.
Requirements:
- Logo on the left
- Main navigation links centered or appropriately positioned
- Primary CTA on the right
- Sticky navigation on scroll
- Navigation background should subtly change after scrolling
- Smooth transition between states
- Mobile hamburger navigation
- Clear active/hover states

Do not make the navbar visually heavy.

---

# 4. VISUAL DESIGN SYSTEM

Create a consistent design system based on the inspiration image and my content.

### Typography
Use a premium modern font pairing with clear hierarchy between Eyebrow, H1, H2, H3, Body, Captions, Buttons. Large editorial typography where appropriate.

### Colors
Extract the visual mood from the reference image (sleek architectural aesthetics, warm minimal tones, refined dark surfaces, subtle lime/citron accent touches, clean light surfaces).

### Spacing
Generous, deliberate whitespace and consistent breathing room.
